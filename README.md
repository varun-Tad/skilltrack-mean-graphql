# SkillTrack

A MEAN stack learning platform with GraphQL APIs.

## Features

- Role-based authentication (student/instructor/admin)
- Course creation and management
- Lessons and quizzes
- Progress tracking
- GraphQL API with Apollo
- Angular frontend with reactive forms

## Tech Stack

- Angular
- Node.js
- Express
- MongoDB
- GraphQL (Apollo)
- Redis
- Docker

## Setup

```bash
npm install
npm run dev
